# Barsha Bakshi Website — V3

A mobile-first, animated personal-brand website using **only the photos supplied in the conversation**.

## Visual direction
The palette is based on the supplied Gyanirman reference:
- Deep teal
- Sage/mint
- Warm gold
- Taupe/brown
- Cream/white
- Charcoal typography

The layout is intentionally different from Gyanirman. It uses editorial typography, handwritten/script accents, layered photo cards, subtle motion, scroll reveals, floating stats and hover interactions.

## Run
No build step is required.

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## Deploy
Upload the contents to GitHub and enable GitHub Pages, or import the repository into Vercel as a static site.

## Replace later
Future testimonials, speaking photos and awards can be added to `assets/images/` and inserted into the matching sections.

## Important
The ₹3L+ figure is presented as a student-result/earnings figure and is not a promise or guarantee of future income.
